# Мейрамханаға тапсырыс беру ақпараттық жүйесі

## Жоба мақсаты
Мейрамхана қызметін цифрландыру арқылы клиенттерге смартфоны арқылы QR-кодпен тағам таңдауға, үстелді алдын ала броньдауға мүмкіндік беру, сондай-ақ қызмет көрсету уақытын үнемдеу.

## Пайдаланушылар және олардың рөлдері
1. **Клиент (Пайдаланушы):** Тағамға онлайн тапсырыс беру және онлайн төлем жасау.
2. **Аспаз (Асхана қызметкері):** Тапсырысты қабылдап, дайын болғанда «Дайын» батырмасын басу.
3. **Администратор / Менеджер:** Жүйені басқару, мәзірге жаңа тағамдар қосу, бағаларды өзгерту.
4. **Официант:** Дайын болған тапсырыстарды клиентке жеткізу.

## Функционалдық талаптар
- ФТ-01: Мәзірді көрсету
- ФТ-02: Сұрыптау және іздеу
- ФТ-03: Корзинаны басқару
- ФТ-04: Тапсырысты жіберу
- ФТ-05: Онлайн төлем (Kaspi QR)
- ФТ-06: Статусты жаңарту
- ФТ-07: Мәзірді редакциялау
- ФТ-08: Хабарлама беру

- **US-06:** Мен админ ретінде, күндік сатылым есебін автоматты түрде көргім келеді, себебі қаржылық көрсеткіштерді бақылап отыру үшін.
