# Use Case және User Story сипаттамасы

## User Stories:
- **US-01:** Мен клиент ретінде, үстелдегі QR-кодты сканерлегім келеді, себебі даяшыны күтпей-ақ электронды мәзірді жылдам ашуым керек.
- **US-02:** Мен клиент ретінде, тағамдарды Kaspi QR арқылы төлегім келеді, себебі қолма-қол ақша немесе терминал күтіп уақыт жоғалтпауым керек.
- **US-03:** Мен клиент ретінде, тапсырысымның дайындалу статусын көріп отырғым келеді, себебі тамағымның қашан дайын болатынын нақты білуім керек.
- **US-04:** Мен аспаз ретінде, келіп түскен тапсырыстарды арнайы экраннан көргім келеді, себебі қағаз чектерсіз тағамдарды кезегімен әрі қатесіз дайындауым керек.
- **US-05:** Мен админ ретінде, таусылып қалған тағамды мәзірде уақытша бұғаттағым келеді, себебі клиенттерден орындалмайтын қате тапсырыстарды қабылдамау үшін.
