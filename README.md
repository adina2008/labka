# Restaurant Ordering Information System (Ресторанның тапсырыс беру ақпараттық жүйесі)

Бұл жоба — Ресторанның тапсырыс беру жүйесіне арналған реляциялық деректер қоры (PostgreSQL DB Fiddle платформасында орындалған).

## 📁 Жобаның құрылымы:
* `script.sql` — Деректер қорының кестелерін құру (`CREATE TABLE`) және бастапқы мәліметтерді қосу (`INSERT INTO`) скрипті.
* `queries.sql` — Аналитикалық SQL сұраныстар (`SELECT`, `GROUP BY`, `HAVING`, `AVG`, `ORDER BY`).

## 🛠 Кестелер құрылымы:
1. **User** — Пайдаланушылар (клиенттер, аспаздар, админдер).
2. **Dish** — Мәзірдегі тағамдар мен бағалар.
3. **Order** — Тапсырыстар.
4. **OrderItem** — Тапсырыстың құрамы.

## 🚀 Қалай іске қосуға болады:
1. [DB Fiddle](https://www.dbfiddle.uk/) сайтын ашыңыз және деректер қоры ретінде **PostgreSQL** таңдаңыз.
2. `script.sql` файлының ішіндегі кодты **Schema SQL** өрісіне вставьте етіңіз.
3. `queries.sql` немесе керекті сұраныстарды **Query SQL** өрісіне вставьте етіңіз.
4. **Run** батырмасын басыңыз.
